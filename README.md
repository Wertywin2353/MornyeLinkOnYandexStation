# Mornye Link On Yandex.Station
Adds basic Mornye Link support to jailbroken Yandex Station (2-gen only)

## About project
This project was coded by ChatGPT and tested on real Yandex.Station 2. Works with Mornye v5.4.0

https://github.com/mornyeapp/Mornye

More about Yandex.Stations jailbreak

https://github.com/Marker284/yandex-station-extended/blob/main/docs/start/index.md#firmware-version

## Avaible features
1. Playing songs via Mornye Link
2. Basic controls (but song scrolling is not avaible, tech issues on Station side)
3. [BETA] LED Music visualisation (disbale any LED effect to avoid conflicts)
4. No Internet needed (probably, cuz realized thru local connection)
